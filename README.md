# Автотесты виджета Учи.ру

Тестовое задание на стажировку AQA. Тесты написаны на TypeScript и Playwright.

## Запуск

Нужны Node.js 22 и npm. Версия Node.js указана в `.nvmrc`.

```bash
npm ci
npx playwright install chromium
npm test
```

Для запуска с открытым браузером: `npm test -- --headed`.
Посмотреть HTML-отчёт: `npx playwright show-report`.

## Что изменил

- Исправил локаторы кнопок открытия и «Написать нам». Для обращения в поддержку использовал `data-test` вместо общего CSS-класса.
- Убрал получение массива статей через `all()`. Теперь клик по первой статье дожидается её появления.
- Заменил чтение текста заголовка на `toHaveText()`, чтобы проверка ждала перехода к форме поддержки.
- Добавил закрытие cookie-баннеров через DOM-клик, чтобы их анимация и дубликаты не мешали тестам.
- Ограничил время ожидания действий и загрузки страницы. На весь прогон отведено 90 секунд.
- Настроил сохранение скриншота и trace при падении теста. HTML-отчёт открывается вручную.
- Добавил один тест: после открытия виджета проверяется, что первая популярная статья видна и у неё есть название.
